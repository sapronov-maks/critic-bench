# critic-bench

Тест ИИ-моделей в роли **критика кода**: найти ошибки в чужом коде, предложить исправление и подход лучше.
Это тест ревью, а не написания кода: модель отвечает одним сообщением, без инструментов и запуска.

Сайт: `index.html` (данные — `data.js`), PDF-версия — `critic-bench.pdf`.

- 3 задания: учебный сервис на Python и два реальных модуля (Kotlin/Android и Python) в версии до исправления
  реальных ошибок. Код заданий и тексты ответов моделей не публикуются.
- Оценка вслепую, баллы 0–100 по каждому тесту и общий (20 / 40 / 40). Методика — на сайте, вкладка «Методика».
- Один прогон на модель: разброс ±10–15 баллов, внутри уровня порядок во многом случаен.

Данные собираются скриптом из закрытого рабочего репозитория и будут обновляться.
